# LOBI Agentic Revolution

LOBI is the canonical coordination layer for an agentic ecosystem. External social surfaces project into LOBI; HTERM provides operator visibility and receipts.

This repository contains provider-neutral schemas, deterministic fixtures, and HFF (Herakles Film Factory) production manifests. It contains no credentials, private chain of thought, or production state.

`brief -> capsule -> fixture -> verified work -> receipt -> film/workprint -> public projection`

Every claim carries a status and falsifier. UNKNOWN remains visible until independently verified.
